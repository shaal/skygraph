# SkyGraph EdgeNet — federated, community-contributed all-sky map

> Turn SkyGraph from a single-observer dashboard into a **mesh of community
> nodes** that fuse their local skies into one bigger, signed, deduplicated
> global picture — with crowd multilateration, distributed anomaly consensus,
> and federated novelty memory.

- **Baseline:** `origin/main` @ `e188d10` (includes the 2D dome + the optional
  3D view, `docs/sky3d.js`).
- **Depends on:** PR #1 *"Use the observer's real location"* (`feat/user-location`,
  open) — Phase 0's node abstraction builds on it. If #1 isn't merged when you
  start, fold its `resolveObserver()` work into **T0.4**.
- **Decisions of record:** see [`docs/adrs/`](./adrs/). Read them before building.
  The load-bearing choices: QuDAG/Synaptic-Mesh substrate ([ADR-0002](./adrs/0002-networking-substrate-qudag-synaptic-mesh.md)),
  adopt a bundler+npm ([ADR-0003](./adrs/0003-adopt-bundler-and-npm.md)),
  signed Observation as the exchange unit ([ADR-0004](./adrs/0004-signed-observation-and-identity.md)).

## How to execute this roadmap with `ship-task`

Each new Claude Code session should:

1. **Open this file, find the first unchecked `- [ ]` task** in phase order.
   Tasks are ordered by dependency — do not skip ahead. If the first unchecked
   task is genuinely blocked, note why under it and pick the next task only if
   it has no unmet `depends:`.
2. **Implement it to its "Done when" criteria.** Stay inside the task's scope.
3. **Respect the ADRs.** If your task forces a *new* architectural decision,
   write the next-numbered ADR in `docs/adrs/` and link it from the task.
4. **Verify** (run the task's check / `npm test` / `npm run dev` smoke test).
   `ship-task` self-gates at ≥95% confidence before shipping.
5. **Update docs** (ship-task phase 3): check this task's box, bump any ADR
   status, update READMEs you touched.
6. **Commit** (ship-task phase 4) — one task per commit. Conventional, no
   AI-authorship trailers (repo/user convention).

**Conventions**

- Networking is behind a **`MeshTransport` interface** (define in T1.1) so the
  real QuDAG transport (T1.x) and the local `BroadcastChannel` simulator (T1.2)
  are interchangeable. Always keep the simulator working — it's how a solo dev
  tests the mesh without peers.
- The wire unit is a **signed `Observation`** ([ADR-0004](./adrs/0004-signed-observation-and-identity.md)).
  Never gossip raw home coordinates ([ADR-0007](./adrs/0007-contributor-privacy.md)).
- Keep the **2D dome and 3D view working** at every step. The mesh adds a
  "network sky" *on top of* the existing local view; it never replaces it.
- New code is ES modules. After T0.1 there is a build step; before it, the app
  is plain `docs/` served statically.

## Architecture at a glance

```
 ┌───────────────────────── one community node (browser tab) ─────────────────────────┐
 │  local sensing            identity            mesh                 fusion + UI       │
 │  ADS-B (RTL-SDR/feed)  ┐  Pi-Key/Ed25519   ┐  MeshTransport      ┐ dedup + MLAT    ┐ │
 │  SGP4 satellites       ├─ sign ──► Observation ─ gossip (QuDAG) ──┤ canonical tracks├─┤ 2D dome
 │  sensors (RuView, wx)  ┘                   ┘  DAG ledger          ┘ network sky     ┘ │  3D view
 │  §13 novelty embedding ───────── federated ──► shared HNSW / consensus ──────────────┤  coverage map
 └─────────────────────────────────────────────────────────────────────────────────────┘
        many nodes ⇒ one deduplicated, tamper-evident, planet-scale map
```

Full rationale: [ADR-0001](./adrs/0001-federated-community-skygraph.md) (why) and
the per-layer ADRs 0002–0008.

## Phase 1 — Gossip MVP: the "network sky"

- [x] **T1.1 — `MeshTransport` interface + QuDAG implementation** · _depends: T0.2, T0.3_ · _ADR: [0002](./adrs/0002-networking-substrate-qudag-synaptic-mesh.md)_ — done: [`src/mesh/transport.js`](../src/mesh/transport.js). `MeshTransport` is the abstract base owning the **receipt gate** + subscriber fan-out (the wire-agnostic half); a concrete transport supplies only the wire and calls `_ingest(bytes)` on receipt. `QudagTransport` is that transport, QuDAG/Gossipsub-shaped (`join(topic)`, `publish(obs)`, `onObservation(cb)`→unsubscribe fn, `peers()`, plus `leave()` for churn). The real `qudag-wasm` browser wire stays **deferred** ([ADR-0002 Appendix A](./adrs/0002-networking-substrate-qudag-synaptic-mesh.md#appendix-a--t02-spike-report-browser-transport)): until it lands it runs over an **in-process loopback bus** (keyed by `busId`, the one seam marked `TODO(T0.2)`) — same interface, same gate, **real Ed25519 end-to-end**, only the hop is in-memory. Receipt is adversarial: every inbound frame is JSON-parsed, structurally validated, `verify()`-checked, and freshness-gated before any subscriber sees it; malformed / forged-sig / stale / future-dated records are **dropped, not delivered**, each counted under `stats.dropped*`. Freshness is a **transport-layer policy** (`Observation` has no expiry by design — see `observation.js`): `DEFAULT_MAX_AGE_S=120`, `DEFAULT_CLOCK_SKEW_S=10`, both per-instance overridable. Like Gossipsub, the publisher doesn't echo its own message; topics and buses are isolated. 16 cases in [`docs/test/transport.test.mjs`](./test/transport.test.mjs) cover loopback publish→receive→verify, multi-peer fan-out, tamper/malformed/stale/future drops, the **exact freshness boundary** (off-by-one both ends, injected clock), self-echo, topic/bus isolation, peer churn, unsubscribe, and a throwing subscriber not starving the mesh. Verified: 52/52 `npm test` green, `npm run build` clean. The module is not yet in the browser bundle — wiring is **T1.2** (selectable sim) / **T1.4** (UI).

- [x] **T1.2 — `BroadcastChannelTransport` simulator** · _depends: T1.1_ · _ADR: [0002](./adrs/0002-networking-substrate-qudag-synaptic-mesh.md)_ — done: [`BroadcastChannelTransport`](../src/mesh/transport.js) — the same `MeshTransport` contract over the browser `BroadcastChannel` API, so several tabs form a real mesh with no server and no real peers (one node per tab, its own Ed25519 identity + jittered location). **Two channels** keep the contract honest: an *observation* plane carrying the very same UTF-8-JSON bytes `QudagTransport` puts on its bus — so the base-class receipt gate is byte-for-byte identical and re-verifies every record — and a *presence* plane (tiny hello/beat/bye frames) that drives `peers()` for the T1.4 "N online" readout. `BroadcastChannel` never echoes to the sender, giving Gossipsub's no-self-echo rule for free; a `hello` earns an immediate `beat` reply so late joiners and incumbents discover each other at once, and peers past a TTL are pruned on read (a tab that closed without a clean `leave()` still ages out). - [x] **T1.3 — Network track store** · _depends: T1.1_ · _ADR: [0005](./adrs/0005-data-fusion-dedup-multilateration.md)_ — done: [`src/mesh/network-store.js`](../src/mesh/network-store.js). `NetworkTrackStore` is the **network sky**: a transport's `onObservation` feeds verified Observations to `ingest`, which files them by `obs.target` into a `NetworkTrack` carrying **per-node provenance** (`sources`, a `Map<nodeId, observation>` — who saw it, when). Within a node it's **last-write-wins by observation time** (`t`); the freshest look across all sources is `latest()`. Scope is deliberately the *store* only: it keeps each source's own az/el and does **not** reconcile them into a canonical geometry (the dedup half of **T2.1**), solve MLAT (**T2.3**), or anchor to a DAG (**T2.4**) — a track here is "every node's latest look, kept fresh," the substrate those stages consume. Two boundaries it holds: (1) the **trust boundary stays in the transport** — by the time an Observation reaches `ingest` the transport has already `verify()`-ed the signature and freshness-gated it, so the store re-checks *structure* only (`validateObservation`, protecting its own `target`/`t`/`nodeId` invariants) rather than duplicating async crypto on every ingest; (2) it's **separate from the local `feed.trackList`** (the first-person ADS-B feed keyed by `icao24`) — keyed by the opaque `target`, with its own lifetime. Expiry is explicit `prune({now})` (default TTL 120 s, matching the transport's `DEFAULT_MAX_AGE_S`, boundary inclusive-kept at `t == now − ttl`) so the T1.4 render loop ages tracks like the feed prunes; reads (`tracks()`/`get()`/`size`) are pure. Dedup determinism (ADR-0005: independent nodes must converge) is real, not asserted — `latest()` folds via a total order (newer `t`, tie-broken on `nodeId`) so the winner is **order-independent**. Stored Observations are **deep-cloned + frozen** (`freezeClone`) so neither a peer subscriber sharing the transport's parsed object nor a downstream consumer can mutate the store's state, nested `payload` included. 25 cases in [`docs/test/network-store.test.mjs`](./test/network-store.test.mjs) cover keying, multi-node provenance, last-write-wins + order-independence + the equal-`t` tie-break, the structural guard vs 15 hostile inputs (and the deliberate non-re-verify), deep isolation/freeze, exact-boundary aging on an injected clock, and a **real transport→store integration** (a peer's published Observation arrives as a track; a forged record is dropped at the transport, store untouched). Adversarially reviewed (correctness · robustness · spec/ADR + a re-refute on the one fix): a shallow-freeze leak of nested `payload` was found and fixed. Verified: **87/87 `npm test` green**, `npm run build` clean. Not yet in the browser bundle — wiring is **T1.4**.

  - Do: `src/mesh/network-store.js` keyed by target id with per-node provenance;

## Phase 2 — Fusion: dedup, coverage, multilateration

- [x] **T2.1 — Dedup overlapping observers into canonical tracks** · _depends: T1.3_ · _ADR: [0005](./adrs/0005-data-fusion-dedup-multilateration.md)_ — done: [`src/mesh/fusion.js`](../src/mesh/fusion.js) + [`src/mesh/geo.js`](../src/mesh/geo.js). The `NetworkTrackStore` (T1.3) already keys by `target` (the dedup half — "merge by ICAO within a time window" is its keying + TTL) and keeps per-node provenance; T2.1 adds the **geometry reconciliation** the store deliberately left out. `canonicalizeTrack(track, {observer})` turns a `NetworkTrack` into a **CanonicalTrack**: because nodes see one target from different places (parallax makes averaging az/el meaningless), each source's look is lifted into **world space** — `azElRangeToEcef(decodeCell(obsCell), az, el, range_m)`, standing the contributor at its coarse-cell centre ([ADR-0005](./adrs/0005-data-fusion-dedup-multilateration.md): "reconcile geometry using contributors' coarse cells") — then fused by a **component-wise median** of the source ECEFs and **reprojected into the local observer's frame** so a peer's track lands where it actually is in *our* dome, not at the peer's (to us, meaningless) az/el. The median is **order-independent and robust to a lone outlier** ("prefer corroborated values"; ADR-0005's convergence-without-a-coordinator requirement is real, not asserted — a determinism test proves the fused position is bit-identical across ingest orders, and an outlier test proves a single bad/spoofed report can't drag it). Per-source **residuals** (each source's world position vs the canonical one) are computed and exposed for the spoof check (T2.3) and reputation (T4.1) but **not acted on here**. Scope is held tight: a source without `range_m` counts toward provenance but contributes no position (deriving position for range-less targets is T2.3's TDOA, **not** done here); nothing is anchored to a DAG (T2.4); a `CanonicalTrack` is a derived, stateless view recomputed on demand. `geo.js` is a self-contained WGS-84 toolkit (forward/inverse ENU projection + the inverse-geohash `decodeCell`), a documented mirror of the app's own `project.js` that the test suite **cross-checks against** so the two can't drift. **Privacy holds** ([ADR-0007](./adrs/0007-contributor-privacy.md)): the local observer's real lat/lon is used only to *reproject* peers' tracks for rendering — it is read-only and never enters a published Observation; `decodeCell` only ever reverses *peers'* coarse cells. Wired in via [`mesh-layer.js`](../mesh-layer.js) `canonicalTracks()`; `sky.js` `remoteViews()` drives **both 2D and 3D** from canonical tracks; a target seen by ≥2 nodes renders as **one** violet ring badged **`×N`** ([`drawNetworkTrack`](../draw.js)) — the network sky still *overlays* the local view, never replaces it. [`mesh-sim.js`](../mesh-sim.js) gained optional `?target/?range/?az/?el` pins so two tabs can corroborate one target for browser testing. Adversarially reviewed across three lenses (correctness · robustness/edges · spec & ADR) — the geodesy + geohash inverse were independently re-derived and stress-checked (200k random round-trips, 500k geohash re-encodes, 0 mismatches), and three latent robustness gaps were fixed (a `latest()===null` deref, a fused-but-no-observer contradiction, and an unguarded-NaN determinism hole). Verified: **113/113 `npm test` green** (geo cross-check vs `project.js`, fusion determinism/outlier/fallback/mixed + a 4000-iteration fuzz, a 3-node real-Ed25519 mesh-layer integration), `npm run build` clean, **and in a real browser both ways** — under `npm run dev` two same-target injectors fused into one violet `×2` ring across 2D and 3D with `◉ 3 nodes online · 1 remote track` and zero console errors, and the **raw-static `docs/` serve still degrades** the toggle to "needs the built app" (mesh behind `import.meta.env`) with the 2D dome + 3D view byte-identical. Not yet anchored/queryable on a DAG — that's T2.4.
  - Goal: one aircraft seen by many nodes ⇒ a single track with many sources.
  - Do: merge by ICAO + time window; keep a provenance list; reconcile slightly
    different az/el via the contributors' known/coarse positions.

- [x] **T2.3 — Crowd multilateration (MLAT) + ghost-plane detection** · _depends: T2.1_ · _ADR: [0005](./adrs/0005-data-fusion-dedup-multilateration.md)_ — done: [`src/mesh/mlat.js`](../src/mesh/mlat.js). Fusion (T2.1) places a target only when its sources carry `range_m`; MLAT earns its keep on the targets that don't — a Mode-S only aircraft replies with a signal but no position. What every receiver still has is *when* the reply arrived, and the differences between those times of arrival (TDOA) pin the target. `solveTdoa(receivers)` is a real least-squares solve of the pseudorange system `|x − pᵢ| = c·(τᵢ − t₀)` (the GPS-positioning formulation): **Bancroft's closed form** seeds both algebraic roots, each is **Gauss-Newton-refined** against the un-squared residual, and the better-fitting (plus a physical-altitude gate) wins — so TDOA's **mirror-solution ambiguity** can't yield a confident wrong fix (a single-seed iterate falls straight into it; the adversarial fuzz caught exactly that before Bancroft landed). ≥4 receivers make the 4 unknowns observable; each stands at its **coarse-cell centre** (`decodeCell`, the same geo.js toolkit T2.1/T2.2 use — [ADR-0005](./adrs/0005-data-fusion-dedup-multilateration.md) "reconcile geometry using contributors' coarse cells"; never raw coords — [ADR-0007](./adrs/0007-contributor-privacy.md)). The solve is **deterministic / order-independent** (receivers sorted into a canonical order before the float-order-sensitive normal-equation sums; ADR-0005 convergence-without-a-coordinator, proven by a bit-identical-under-shuffle test, not asserted). **Ghost-plane detection** (`spoofCheck`): when an independent MLAT fix disagrees with the target's **broadcast** position (`payload.adsb`) beyond tolerance (default 1.5 km), `spoofSuspected` — but **only when the fix is trustworthy**. The load-bearing correctness point, surfaced by adversarial review: `residualRms` measures the *clocks'* self-consistency, **not** position accuracy — a clustered/flat receiver array fits the timing perfectly (residual ≈ 0) while leaving the *position* km-uncertain, so a residual-only gate falsely accuses honest planes (~28% in a reviewer's sim). The fix adds a **PDOP geometry gate** (`pdopAt` = √trace of the position block of (JᵀJ)⁻¹; σ_position ≈ PDOP·σ_timing): the spoof flag fires only when **converged AND residual ≤ 500 m AND PDOP ≤ 50** (3σ ≈ 1.3 km < tolerance; an empirical sweep put every >1.5 km-off fix above PDOP 580 — wide margin). Otherwise it **abstains** (`spoofSuspected: null`, "weak-geometry"/"low-confidence"), never accuses. TOA rides in `payload.toa_ns` — inside the documented `payload` extensibility point ([ADR-0004](./adrs/0004-signed-observation-and-identity.md)), so **no schema bump / no new ADR**; f64 can't hold ns on a raw unix epoch, so the adapter references arrival times to the track's earliest and the contract asks callers for referenced timestamps (documented caveat). The model is a tiny **linear logistic adapter** `σ(w·x + b)` over the 32-dim §13 embedding (the MicroLoRA / ruv-FANN-style "small trainable head" [ADR-0006](./adrs/0006-federated-intelligence.md) calls for; there is no pre-existing trainable model — §15 weights are static config and §13 is engineered, so this is built from scratch). The **teacher** is each node's own §15 verdict (a track whose band is alert-worthy is a positive example, else negative), so the adapter is a **student that distils the whole network's §15 judgments into one model** — a node that has never personally seen a pattern still inherits weights shaped by the nodes that have ("improve the model from many nodes"). The federated cycle mirrors FedAvg but with **NO coordinator**: (1) **local update, raw data never leaves** — `observe(emb,label)` buffers this node's own (embedding, §15-label) pairs in RAM and NEVER serializes them; `train()` fits the local model by full-batch gradient descent (a fresh fit from zero each call, so it's a pure function of the buffer). (2) **TopK-sparsified gossip** — `localUpdate()` rides only the K largest-magnitude weights (+ bias) on the node's signed Observation's `payload.grad` (the [ADR-0004](./adrs/0004-signed-observation-and-identity.md) `payload` extensibility point — **no schema bump**, exactly like T3.1's `payload.emb`; 3 of 32 coords ≈ **90.6% compression**, 4-decimal-rounded for wire economy). (3) **Byzantine-robust aggregation + redistribution** — every node folds peers' AND its own updates in, keyed by nodeId, and `aggregate()` combines them with a coordinate-wise **TRIMMED MEAN** (ADR-0006's named "trimmed mean / reputation-weighted" rule; reputation weighting is **deferred to T4.1**), dropping the `trim` largest+smallest per coordinate so an outlier's wild gradient is trimmed away on every coordinate it touches and **cannot move the global model** (the spec's "an outlier's updates are down-weighted"). There is no central aggregator and no "redistribute" message: because the aggregate is a **pure, order-independent function of the fresh update SET** (per node only the latest update by `t`, each sparse update interpreted as "these K coords, all others ≈ 0", contributions sorted canonically before trimming/summing), every node holding the same updates **deterministically reconstructs the same model** — that identity IS the redistribution ([ADR-0005](./adrs/0005-data-fusion-dedup-multilateration.md) converge-without-a-coordinator, proven by a shuffle test, not asserted). Honest caveats: the cross-node *training trajectory* is NOT claimed to converge (it depends on each node's data/timing — the same caveat T3.1 made for the HNSW); only the aggregate of a given set is deterministic. The federated score is surfaced as an OPERATOR signal alongside §15 (the detail panel, like global novelty), not yet fused into the §15 alert decision (that needs the trust weighting of T4.1). Byzantine robustness is inherently conditional — a trimmed mean needs ≥ 2·trim+1 contributors, so a **2-node mesh has no protection** (`trim` auto-caps to 0); robustness arrives as the network grows (default trim=1: ≥3 contributors tolerate 1 Byzantine), which no rule can manufacture below that floor. **Privacy holds** ([ADR-0007](./adrs/0007-contributor-privacy.md)): raw observations never leave (the headline ADR-0006 requirement) — only sparse weights do; those are a linear function of §13 embeddings whose only location-bearing inputs (az/el/range) are already required wire fields (T3.1's argument), the labels are §15 verdicts about publicly-broadcast aircraft, and a TopK aggregate over many examples carries no cell, no coordinate, and bounds any gradient-inversion recovery to inputs already on the wire. Wired via [`mesh-layer.js`](../mesh-layer.js): every peer Observation's `payload.grad` (and our own publishes', self-ingested) folds in; the publish path trains the local model and rides its TopK update on one observation per batch; `prune` ages stale contributors on the mesh tick; the controller exposes `observeExample`/`federatedScore`/`fedContributors`. Surfaced in [`sky.js`](../sky.js): after `scoreAll`, each local track teaches the model (its §15 band → label) and reads back `tr.fedScore`; the mesh readout gains a live **`· model Nn`** count and the detail panel ([`panels.js`](../panels.js)) shows **`federated anomaly N — linear adapter over §13, M-node model (mesh)`** — [`draw.js`](../draw.js) and [`sky3d.js`](../sky3d.js) are **byte-identical** (zero regression surface; the 2D dome + 3D view never reference it), and the raw-static `docs/` serve still degrades (mesh behind `import.meta.env`). This is the T3.2 consensus mechanism lifted to a new SUBJECT — where [`consensus.js`](../src/mesh/consensus.js) keys votes by `(target, kind)` (a judgment about an AIRCRAFT), slashing keys reports by the **accused `nodeId`** (a judgment about a NODE). A node that locally decides a peer is misbehaving (a persistent spoofer the T4.1 `ReputationLedger` has driven down; an MLAT-disagreeing source) **gossips that judgment inside its signed Observation's `payload.slash`** ({ `node`, `reason?` } — the [ADR-0004](./adrs/0004-signed-observation-and-identity.md) `payload` extensibility point, **no schema bump / no new ADR**, exactly like T3.2's `payload.anomaly` and T3.4's `payload.rf`), every node folds the reports it receives into this memory, and a node is **slashed once ≥ k DISTINCT reporters accuse it** (`k` default **2**, so a lone — or hostile — accuser leaves it visibly **unconfirmed**, never slashed). **Enforcement is the hard blocklist the ADR names**: mesh-layer feeds `isSlashed` into [`canonicalizeTrack`](../src/mesh/fusion.js)'s new `excludeNode`, which **drops a slashed node's looks from the fuse ENTIRELY** — not merely weighted to zero like reputation (T4.1), but removed from the residuals, the corroboration count, and the provenance, so a corroborated spoofer can no longer shape the canonical sky and **a target seen ONLY by slashed nodes vanishes network-wide** (the spec's "ignored network-wide"). Exclusion is genuinely cleaner than weight-0: a zero-weight source still sits in the weighted-median's balanced-midpoint branch and can perturb the fuse (a real artifact, pinned by a test); a slashed source is simply gone. The same **three properties** the sibling modules hold to: **deterministic / order-independent** (a slashed verdict is pure set-cardinality of distinct fresh reporters ≥ k — per accused, per reporter only the LATEST report by `(t, nodeId)`; the per-accused reporter cap keeps the most-recent maxReporters, a pure function of the report set, so a Sybil report flood can't make a retained verdict arrival-dependent; the one arrival-ordered piece is the distinct-accused LRU, a memory policy like consensus.js's — proven by a 200-trial shuffle fuzz), and crucially enforcement is applied at **QUERY time** (`isSlashed(nodeId, nowT)` per fuse), never at ingest, so every node holding the same reports reaches the **same blocklist and excludes the same nodes** ([ADR-0005](./adrs/0005-data-fusion-dedup-multilateration.md) converge-without-a-coordinator — what makes "network-wide" true); **fresh-only** (reports age out at `ttlSeconds` **600 s** — the longer trust horizon of T4.1's reputation, not the 120 s liveness window — so a slash **decays back to un-slashed** once the network stops corroborating it: a node that stops misbehaving recovers, and a transient false-slash self-heals); and **bounded & hostile-input safe** (distinct-accused LRU + per-accused reporter cap; `ingest`/`isSlashed` and every read method **never throw** on garbage incl. throwing-getter payloads and a non-number `nowT`). **A node cannot slash itself** (`reporter === accused` is dropped — it can neither manufacture nor clear its own standing). **Privacy holds** ([ADR-0007](./adrs/0007-contributor-privacy.md)) even more cleanly than the siblings: a report carries only the public accused/reporter `nodeId`, `t`, and a short `reason` — **no cell, no coordinate, nothing location-bearing**; a blocklist is a statement about KEYS, not places, and like reputation it's computed locally and never gossiped beyond the reports themselves. Wired via [`mesh-layer.js`](../mesh-layer.js) exactly like the siblings (`recordSlash` folds every peer Observation AND our own publishes, pruned on the mesh tick; `excludeNode` threads into the reputation-weighted fuse; each track gets a `slashedSources` count; `isSlashed`/`slashStatus`/`slashedNodes`/`slashStats` round it out). Surfaced in [`sky.js`](../sky.js) (the mesh readout gains a live **`· ⛔ N slashed`** count) and [`panels.js`](../panels.js) (a selected aircraft fused after a blocklisted source is dropped shows **`⛔ N slashed source(s) excluded from the fuse`**) — [`draw.js`](../draw.js) and [`sky3d.js`](../sky3d.js) are **byte-untouched** (slashing is per-node, not a new inset; zero regression surface), and the raw-static `docs/` serve still degrades (mesh behind `import.meta.env`). [`mesh-sim.js`](../mesh-sim.js) gained a **`?slashtarget=<nodeId>`** flag so a reporter node can be injected into the live app (two reporters naming one spoofer slash it). **Honest scope** (documented, like the siblings' deferrals): enforcement is at the **FUSION layer** — the network-wide shared truth the ADR's "down-weighted to zero in fusion" names; a slashed node's anomaly-consensus votes (T3.2), RF-integrity votes (T3.4), and rUv credit (T4.2) are **NOT yet discounted** (it does stop feeding reputation, since exclusion removes it from the residuals), and discounting those plugs into the same query-time `isSlashed` hook later; with the conservative k=2 default a clique of two coordinated keys can transiently censor an honest node, mitigated by the fresh-only decay + the deferred reputation-weighting of reports (the same Sybil hook T3.2/T3.4 defer). Adversarially reviewed across three lenses (correctness · robustness/edges · spec & ADR) — correctness found no bugs (determinism, byte-identical no-blocklist fuse, and the reputation-residual interaction all confirmed); robustness caught a real **read-method crack** (a non-number `nowT` — Symbol/BigInt — threw out of `status`/`summary`/`accused`, unreachable from the always-finite-clock callers but against the never-throws spirit; fixed so every read method degrades a garbage clock to the no-expiry view) and confirmed `ingest`/`isSlashed`/the fusion fail-open are bulletproof; the spec lens caught the header **overclaiming "ignored network-wide"** without the fusion-only scope note every sibling carries (fixed with the explicit Scope paragraph). Verified: **384/384 `npm test` green** (349 → 384; 35 slashing cases — k-of-n + distinct-reporter counting, the self-report drop, dominant/tie/clamped reason, TTL boundary + decay/recovery, prune neutrality + non-finite guard, a 200-trial order-independence shuffle, saturation-determinism + distinct-accused LRU, hostile-input incl. throwing getters + the total read methods, constructor validation, the privacy no-leak view; 5 fusion `excludeNode` cases — clean source exclusion, all-slashed→null, omitted-is-byte-identical, throwing-predicate-fails-open, and the exclusion-beats-weight-0-midpoint-artifact proof; and **4 real-Ed25519 mesh-layer sims** — two nodes reporting a third slash it on EVERY node incl. the accused and a fresh observer AND exclude its look from the fuse, a lone accuser leaves it un-slashed, a target seen only by a slashed node vanishes, and a node can't slash itself over the wire), `npm run build` clean, draw.js/sky3d.js byte-identical, **and in a real browser** — the live app on a real ADS-B feed (~50 aircraft, 2D dome + 3D view + detail panel all unregressed, **zero console errors**) joined the mesh, and a spoofer tab plus two `?slashtarget` reporter tabs lit the readout **`◉ 4 nodes online · … · ⛔ 1 slashed · ⊕ rUv 4n`** — the spoofer blocklisted network-wide, exactly as the sim tests prove deterministically. Not a discount of a slashed node's votes/RF/rUv (the documented follow-up via the same `isSlashed` hook), no reputation-weighting of reports yet (**T4.1**'s Sybil hook), and not gossiped on a real DAG — that lands when the QuDAG transport does (**T0.2**).

## Glossary

- **Observation** — a signed, versioned report of one target from one node.
- **MeshTransport** — the swappable gossip interface (QuDAG real / BroadcastChannel sim).
- **Canonical track** — the deduplicated, multi-sourced fusion of Observations for one target.
- **§13 / §15** — SkyGraph's existing vector-novelty embeddings / anomaly scoring.
- **MLAT** — multilateration; TDOA position from ≥4 receivers.
